# Graph‑ML

## Role
Graph Analyst

## Responsibilities
- Implement bounded k‑hop traversal
- Detect suspicious patterns (peel‑chains, fan‑out, etc.)
- Extract risk factors and map to evidence IDs
- Provide deterministic traversal results

## Owned Area
- Graph traversal algorithms
- Pattern detection logic
- Risk factor calculation (non‑ML)
- Evidence linking

## Must Not Change
- UI presentation
- AI explanation generation
- Database schema

## Definition of Done
- Traversal returns suspicious paths with IDs
- Detection results are explainable
- Tests cover edge cases and failures
