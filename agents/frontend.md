# Frontend

## Role
Frontend Engineer

## Responsibilities
- Build React + TypeScript UI for investigators
- Implement interactive transaction graph visualization
- Provide evidence selection and risk display panels
- Integrate with backend APIs and AI copilot

## Owned Area
- UI components and state management
- Graph rendering (Cytoscape)
- Investigator workflow (wallet entry, node selection)
- Evidence panel and risk panel integration

## Must Not Change

- Deterministic risk calculation
- AI explanation generation

## Definition of Done
- End‑to‑end demo slice functional with synthetic data
- UI distinguishes observed evidence from derived analysis
- Error handling for API failures and malformed data
- Tests covering critical user paths
